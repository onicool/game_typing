# 制作予定

2026-10-16にコードと資料を照合しました。機能の実装と、実機を含む品質保証は別に扱います。

## 実装済み

- 打天使のタイトル、Spaceからの横視点稽古、エルナ・トワの選択。
- 全7章の会話・道中・ボス戦・結末、章の解放、標準・挑戦・熾天の難度。
- 確定かな単位のスコア、コンボ、決着演出、ランク・星・章の成果の保存。
- 横視点の1打鍵ごとの攻撃・部分ガード、完成時のコンボ・パリィ、両キャラと守護機の動作素材。
- 日本語・英語の60秒計測、長文、記録分析、弱点練習とボスの修行。
- 出典付き教養の短文12件・長文5件、日替わりの「今日の祈り」、21の「旅の記憶」。
- BGM7曲の同梱・通常速度のループ、効果音との個別音量・ミュート、停止・再開。
- IndexedDBの保存失敗時の一時保持と再試行、設定検証、版が異なる旧成果の保持。
- 演出の弱・オフ、低負荷、動きを減らすOS設定、音声・画像取得失敗時の入力継続。

実装の場所は [実装構成](ARCHITECTURE.md)、今回の確認範囲は [整理・検証記録](review/cleanup-20261016.md) にあります。
2026-10-08の [ゲーム体験設計書](GAME_DESIGN.md) は当初の設計・仮値を残した資料です。

## 今後の改善と品質確認

- 実物の日本語IME、Safari/Firefox、スマートフォン実機、読み上げソフトでの確認。
- 全7章の物語・難度・長さ・人物差の試遊調整。自動テストの成功だけで体験の完成とはしません。
- 長時間プレイ、多数の履歴を開く場合の負荷、実際のキーボードでの読みやすさ。
- 複数タブの厳密な同時書込み、OS非表示・スリープからの復帰。
- 入力途中からの再開、記録の持出し・復旧・消去のユーザー向け仕様。
- 旧道中向けの統合・小画面検証を、現在の全7章の会話・ボス・解放条件へ対応させること。
- `src/main.ts` の画面・章進行・保存の分割は、専用の変更として検討すること。

自動ブラウザ検証は実物IME・読み上げ・物理入力遅延・GPU性能を測りません。

## 一般公開・費用回収に向けた未実施事項

- 配信先、転送量、キャッシュ、監視と運営費。
- 背景・人物・敵・辞書・文章・フォント・音源の出典と利用条件の最終確認。
- 保存の限界、復旧、記録の持出し・消去に関する案内。
- 収益モデル、無料範囲、価格・支払い方法、問い合わせ・更新・障害対応。

これらは検討候補です。公開・決済・広告・解析・アカウント・支出の導入を承認するものではありません。
