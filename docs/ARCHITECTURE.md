# 実装構成

現在の入口は `index.html` → `src/main.ts` です。天使の選択、旅の地図、練習、記録、
入力、結果の画面を同じページ内で切り替えます。Viteはこの単一HTMLをビルドし、
存在しないページへのアクセスは404として扱います。

## 入力と道中

- `src/game/journey.ts`: 姉弟、7土地、各5語の順序、直近の打鍵速度表示。
- `src/game/round.ts`: 出題、二つの先読み、時間、入力ログ、停止・再開、終了と結果。
- `src/engine/romaji.ts`: 日本語の別綴り、かなの進捗、英語、長文の句読点。
- `src/content/`: 日本語・英語・オリジナル長文と、使用する原画/WebPの一覧。

道中と長文は時間制限なし。通常計測と弱点練習は60秒です。IME、長押し、修飾キー、
操作部品にフォーカスがある間のキーはゲーム入力から分離します。

## 表示・音声

画面はDOMとCSSです。ローマ字と読みは入力位置に追従し、次の二つの出題を表示します。
背景と人物は `public/angel/` から配信します。原画は `concept/` に保管します。
動きを減らす設定と低負荷設定を尊重します。

`src/fx/combat.ts` と `src/fx/combat.css` は、ステージ1の人型マシンと攻防のSVG演出です。
道中・長文・計測の入力に反応し、ゲーム内の経過時間で予兆・接近・防御・衝撃を切り替えます。
描画要素と粒子数には上限があり、停止中は進みません。HPや入力判定・スコアへの影響はありません。

`src/fx/audio.ts` の効果音は任意です。音声機能が使えなくても入力・保存は続行できます。
`src/ui/dialog.ts` が一時停止と設定のフォーカス移動・背景の操作分離を担当します。

## 保存と分析

`src/stats/store.ts` はIndexedDBの書込み確定を待ち、失敗時はページ内で一時保持します。
未保存分は次の保存で再試行します。確定済みのページ内キャッシュは直近5件に制限し、
DBの履歴は保持します。閉じた分析画面の読み込みは中止します。

`src/stats/analyze.ts` と `src/ui/report.ts` は速度、正確率、キーの遷移、苦手を表示します。
`src/stats/select.ts` は苦手に合わせた出題、`src/stats/baselines.ts` は遷移の基準を扱います。

既存記録を読むため、IndexedDBの `icebreaker-stats` と `icebreaker.*` の設定キーは継続します。
旧画面の削除でユーザーの保存データを消したり、スキーマを初期化したりしません。

## 検証と資料

各機能のユニットテストは対応するソースの隣に置きます。
`checks/` の5本は、天使版の入力・保存・画面サイズ・実時計・攻防演出・JSフレーム処理時間を
確認する追加のブラウザ検証です。共通のブラウザ選択処理は `browser_support.py` に置きます。
過去の確認は `docs/review/`、制作上の未確定事項は `docs/ROADMAP.md` に置きます。
旧画面、旧描画、旧素材、旧画面専用のブラウザ検証は現在のツリーから削除しました。
