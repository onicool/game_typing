# 旧版の削除とフォルダ整理

確認日: 2026-10-06 JST

## 変更

- 旧ハッキング版のHTML、画面コントローラー、CSS、Canvas描画、専用テストを削除。
- 旧ステージの背景・敵のPNG/WebP、旧画面案と描画補助スクリプトを削除。
- 旧画面専用のブラウザ検証と古い設計・作業メモを削除。
- 天使版の入口を `src/main.ts`、表示を `src/style.css` に統一。
- 道中を `src/game/`、素材一覧を `src/content/` に移動。
- 構成・制作予定・過去の統合確認を `docs/` にまとめ、READMEを現在の内容へ更新。
- 分析の「脆弱性」「パッチ」などを「苦手」「練習」「課題」の表記へ変更。
- 天使版のブラウザ検証は3本を残し、インストール済みのMac Chrome/Linux Chromiumを
  選べる補助処理を共通化。自動ダウンロードや新しい依存追加は行っていない。
- OSの `.DS_Store` を整理し、Gitでの除外を追加。

既存の入力・ラウンド・保存・分析・設定・音声・ダイアログは継続します。
既存記録との互換性を保つため、保存キーとIndexedDBスキーマは変更していません。
姉弟と7土地の原画9枚、本体のWebP9枚、天使版の世界観と画面案は保持しています。
旧版の過去のコミットはGitの履歴に残ります。
