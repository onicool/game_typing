# 白翼の旅 — 空と祈り

天使の姉弟エルナ・トワを選び、言葉を唱えて下界への道をひらくタイピングゲームです。
全7土地の各5語の道中、日本語・英語の60秒計測、長文練習、記録分析と弱点練習を利用できます。
ボス戦、人物ごとの性能差、物語の結末、BGMは制作中です。

## ローカルで試す

既存の依存がある場合は、そのまま起動できます。初回だけ `npm ci` を実行してください。

```sh
npm run dev -- --host 127.0.0.1 --port 5179 --strictPort
```

このMacのブラウザで [ゲームを開く](http://127.0.0.1:5179/)。
起動済みならブラウザを開くだけで試せます。サーバーの停止は起動した端末のCtrl-Cです。

1. 天使を選び、「この天使で旅に出る」を押します。
2. 旅の地図で土地を選び、「この場所へ」を押します。
3. IMEをオフにし、表示されたローマ字を入力します。

ミスはそのまま打ち直し、Backspaceは不要です。shi / siなどの別綴りに対応します。
Escで一時停止します。ボタンや音量などを操作中のEscは入力面に戻ります。
「練習」から60秒計測と長文、「記録」から分析と弱点練習を開けます。

## 保存

記録はこの端末・ブラウザ・オリジンのIndexedDBに保存します。
保存完了は書込み確定後に表示します。保存に失敗した記録はページ内で一時保持し、
次の正常な保存時に再試行します。成功前に再読込・ページを閉じると一時保持分は失われます。
道中・長文・弱点練習・中断した計測は、60秒計測の自己ベスト対象外です。

天使と土地の選択は再読込後に復元します。語の途中からの再開と全章クリア状態の保存は未実装です。
既存の記録を継続して読むため、旧名称を含む保存キーは保持しています。
