# ICEBREAKER — ローカル試作

ブラウザでローマ字・英語・長文を練習するタイピングゲームです。現在の実装は
TypeScript、DOM、Canvas2D、任意の Web Audio、IndexedDB。設計書の将来機能と
実装済みの範囲は異なります。最新の確認結果とレビュー素材は
[LOCAL_REVIEW.md](LOCAL_REVIEW.md)、詳しい履歴は [TODO.md](TODO.md) にあります。

## 起動と確認

この環境では Node 24.19 / npm 11.9 と既存の `node_modules` を使用しました。
新しい環境で依存を用意する場合は、既存の `package-lock.json` に従って
`npm ci` を実行してください。新しい依存の追加は不要です。

```sh
npm run dev -- --host 127.0.0.1 --port 5179 --strictPort
```

本番用ビルドのローカル確認:

```sh
npm test -- --maxWorkers=1
npm run build
npm run preview -- --host 127.0.0.1 --port 5179 --strictPort
```

停止は起動した端末の Ctrl-C。個別の検証手順は [checks/README.md](checks/README.md)。
Python Playwright、Chromium、Pillow、ffmpeg は任意の検証・素材制作ツールで、
アプリや通常のビルドの依存ではありません。

## 操作と記録

- タイトルで Space / Enter: 60秒の日本語・英語計測。最初の文字キーから計時。
  `D` で辞書切替、`R` で分析、`S` で演出設定。
- 「長文練習」: オリジナル4文章の時間制限なし練習。句読点は `,` / `.`。
- 入力面で Esc: 一時停止。ダイアログの「再開」「やり直し」「タイトルへ」を選択。
  長文は「終了して記録を保存」で途中結果を残せます。
- 操作部品にフォーカスがある間、そのキーはゲーム入力になりません。
  Tab / Shift-Tab で移動、Space / Enter はフォーカス中のボタンを操作します。
  プレイ中、操作部品から Esc で入力面へ戻り、次の Esc で停止します。
- ローマ字ガイドの別綴りも受け付けます。ミスは打ち直し、Backspace は不要。
  語末の「ん」は `nn` または `xn`。IME は OFF にしてください。
- 中断後の計測、長文、パッチは練習扱いで、自己ベストを更新しません。

保存完了の表示は IndexedDB の確定後に出ます。「一時保持のみ」の記録は
ページを閉じる・再読込する前に、次の保存が成功すればまとめて再試行します。
分析を開くだけでは再保存しません。端末・ブラウザ・オリジンが変わると記録は
別になります。途中のラウンドはページ内で停止・復帰できますが、再読込後の
途中再開は未実装です。ブラウザのデータ削除・退避でもローカル記録は失われます。
記録の外部同期はありません。

## 現在の見た目と安全な再開

SKYWAY は1ステージ。通常の文字入力に合わせて進行し、各単語の最後の
パケット到達で防壁を破壊します。3語中1語は「迎撃（通常入力）」の見た目ですが、
追加キー・衝突判定・制限時間はありません。大きな固定文字、次の2語、低負荷設定、
動きを減らす設定、素材・Canvas・音声障害時の入力継続を備えています。

WebP は通常配信用、PNG は原本と1回の形式フォールバックとして保持します。
`public/stages/` の PNG、生成原本、過去のレビュー素材は削除しないでください。
RGB の WebP 圧縮は非可逆で、元画像と同一画素ではありません。

現在はローカルブランチ `improve/session-save-feedback` のみで作業しています。
再開前に `git status --short` と `git log -1 --oneline` を確認し、上位案件を優先。
起動済みの検証は有限にし、停止時にはプロセスと進捗の保存先を記録してください。
`main`、本番、公開、push / PR、外部保存は別途許可されるまで変更しません。
品質の目標は入力・保存・可読性・安定性の測定で確認し、有料製品との未実施の
比較を優位性として称しません。

パートナー、追加ステージ、ゲーム構造の拡張はバックログ。BGM は別作業の
検討情報のみで、音源・利用許諾・ループ仕様は未確認です。
