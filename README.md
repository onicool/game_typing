# 打天使（だてんし）

天使の姉弟エルナ・トワと旅するブラウザ用タイピングゲームです。

- 全7章の会話・道中・ボス戦。表示されたローマ字で攻撃し、防御の言葉で反撃を弾き返します。
- 標準・挑戦・熾天の難度、日替わりの「今日の祈り」、21の「旅の記憶」。
- 日本語・英語の60秒計測、長文、記録分析と弱点練習。
- 教養の短文12件と長文5件。一次資料に基づく自作解説と先人の考え方の自作要旨を、出典付きで練習できます。
- 記録と旅の成果は利用中のブラウザに保存します。

## 起動

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5179 --strictPort
```

同じ端末で http://127.0.0.1:5179/ を開きます。タイトル画面でSpaceを押すと、エルナで横視点バトルがすぐ始まります。
「天使を選ぶ」や「旅の地図」から、人物を選んで物語を進めることもできます。
IMEをオフにして表示されたローマ字を入力してください。会話はSpace/Enter、停止・再開はEscです。
「教養の短文を打つ」から60秒の練習へ、「練習」の「長文を練習する」から教養の長文へ進めます。
句読点は `,` と `.` で入力します。人物名と「要旨」は入力本文から分けて表示します。
従来の辞書と記録の識別子は保持し、教養の記録は別の辞書として保存します。

## 横視点バトル

タイトル画面のSpaceキー、または「SPACEでスタート」で、エルナの第1ステージの稽古をすぐ始められます。
天使選択画面の「横視点バトルを遊ぶ」では、選んだ天使で始められます。
「練習」には短文・長文のバトルがあります。教養の文章と出典を表示します。
稽古中は戦闘と現在の文章を優先して表示します。「次の言葉を見る」で次の2文を開けます。
小さな画面では入力欄の中で読み・ローマ字が入力位置を追従します。
縦の短い画面では出典や記録値まで見るためにページのスクロールが必要な場合があります。

正しく受理されたローマ字1文字につき1回、攻撃では光の斬撃、防御では弾の反射を表示します。
`shi` / `si` のような別綴りも実際の打鍵数に従います。誤入力、IME、キーリピートは攻防に数えません。
演出は重ねて即座に出し、長文や高速入力でも後から再生する待ち列を作りません。
高速入力では最新の斬撃を明るく、重なった古い閃光を薄くします。斬撃の命中は金色、
ガードは青い盾、被弾は橙色の割れた線で表示し、完成時のコンボ／パリィは短く残します。

文の長さに合わせた時間内の完成で、攻撃はコンボ、防御はパリィになります。
訂正後の完成も達成になり、ノーミスは追加ボーナスです。途中までの入力も敵へのダメージや部分ガードに残ります。
予告した反撃は小さく分けて到達し、初期設定では防げなかった1回につきガードが2減ります。
時間内に防御文を完成すると、その文の間に受けた小さな被弾を回復してパリィになります。
被弾中も入力できます。停止やタブ非表示の時間は除き、復帰時に反撃をまとめて到達させません。

設定の演出「弱」「オフ」、低負荷と `prefers-reduced-motion` に対応します。
稽古の記録は専用辞書に保存し、旅の解放や従来の自己ベストへ混ぜません。

横視点のキャラクターは、元の設定画をもとに生成した透過WebPです。エルナは筆槍、トワは光輪の手甲を使い、
各キャラは4通常攻撃＋2コンボ技を持ち、6コマで身体・武器を動かします。
エルナは突き・振り下ろし・切り上げ・逆薙ぎと、螺旋・三連突き。
トワはジャブ・クロス・アッパー・掌撃と、双輪連撃・光輪解放です。
人型守護機は射撃・踏み込み打撃・連射を使い、被弾と弾き返しで異なる姿勢に崩れます。
振りかぶり、加速、接触、振り抜き、戻り、待機の順に再生し、足元を共通の接地点へ揃えます。
攻撃順は決定的に切り替わります。読込中や素材取得失敗時は従来の透過姿勢で入力を続けられます。
1打鍵1演出は重ねて表示する光の軌跡が担当し、姿勢を順番待ちで再生しません。
高速入力では身体を接触からの連撃へ移し、全文完成の締めは短く残します。身体の再生待ち列も作りません。
背景と生成素材の説明は [public/battle-art/CREDITS.md](public/battle-art/CREDITS.md) にあります。
武器ごとの生成軌跡・光輪・火花に、KenneyのCC0素材を重ねています。
出典と同梱ライセンスは [public/fx/CREDITS.md](public/fx/CREDITS.md) に記録しています。

## 音声

BGMは開始ボタンを押したあと、打鍵やコンボに合わせず通常速度でループ再生します。
設定でBGMと効果音の音量・ミュートを個別に変更できます。停止や画面を離れたときはBGMも止まります。
再開時は続きから、やり直しや次の章では曲の先頭から再生します。

BGMは `public/audio/music/boss/` に同梱した7曲のSuno生成MP3を再生します。
曲名・生成元URL・ハッシュは同フォルダの `manifest.json` に記録しています。
音源ファイルがない場合は設定に再生不可と表示し、タイピングは続けられます。
このゲームへの利用と公開GitHubでの配布について、音源提供者が条件を確認済みです。
別用途の音源利用はSunoの規約と提供者の許諾に従います。音源の利用条件はコードの条件とは別です。

## 本番ビルドの確認

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 5180 --strictPort
```

同じ端末で http://127.0.0.1:5180/ を開きます。

## 開発時の検証

```sh
npm test -- --maxWorkers=1
npm run typecheck
npm run build
```

ブラウザ検証の準備と実行方法は [checks/README.md](checks/README.md) にあります。
現在の横視点稽古は `side_combat_check.py` で小画面・高速入力・攻防・保存・BGMを確認できます。
`battle_motion_check.py` は両キャラの6攻撃、敵3攻撃、全6コマ、読込失敗時の継続を実ブラウザで確認します。
