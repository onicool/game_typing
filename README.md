# 白翼の旅 — 空と祈り

天使の姉弟エルナ・トワと旅するブラウザ用タイピングゲームです。

- 全7章の会話・道中・ボス戦。表示されたローマ字で攻撃し、防御の言葉で反撃を弾き返します。
- 標準・挑戦・熾天の難度、日替わりの「今日の祈り」、21の「旅の記憶」。
- 日本語・英語の60秒計測、長文、記録分析と弱点練習。
- 記録と旅の成果は利用中のブラウザに保存します。

## 起動

```sh
npm ci
npm run dev -- --host 127.0.0.1 --port 5179 --strictPort
```

同じ端末で http://127.0.0.1:5179/ を開き、天使と土地を選びます。
IMEをオフにして表示されたローマ字を入力してください。会話はSpace/Enter、停止・再開はEscです。

## 本番ビルドの確認

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 5180 --strictPort
```

同じ端末で http://127.0.0.1:5180/ を開きます。
